# Professor OS
This Operating system is a complete Money-Heist Theme. Main moto of this project is to build a basic setup of a operating system highlighting how applications are made after following this money heist theme.

## Features
1. Users can experience some of the common applications like:
   * CALCULATOR
   * CALENDAR
   * PAINT
   * FILE FOLDER
   * TO-DO LIST
   * STOPWATCH

2. All these app's icons and functioning are customized to MoneyHeist theme.
3. There is also a Bella Ciao instrumental music play and mute button.
4. Every application once opened can be minimzed or closed through their application windows header buttons.
5. Every application window size can be movable & scalable.


## Tech Stack
* Frontend: HTML, CSS & JS <br>
* Deployment: Github Pages

## How AI is Used?

figure out errors that are on screen and try to struggle with all the docs from w3 schools and GeeksForGeeks opened in front of me everytime. If I still not able to crack it, I simply ask ai to help me with these so and so errors...bla..bla...bla! It gives me some code to replace here and there.
I first think my mistakes and react accordingly. Surprisingly I made this habit and started tracking some of my mistakes in one small notebook, because it may help me remember in future too...

The only Gen ai tool I used was ChatGPT.
